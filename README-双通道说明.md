# 戈克世界：流脉牌局

八阵营流脉卡牌对战 Demo。当前构建：`20261025e63`。

## 运行

### Windows 桌面版

1. 双击根目录的 `戈克世界-流脉牌局.exe`。
2. 如果 Windows 提示未知发布者，选择“更多信息 → 仍要运行”。
3. 程序会启动本机服务并用 Edge 应用窗口打开游戏。

也可以用 `启动游戏.bat` 作为备用入口。

### 浏览器 / 开发模式

需要 Node.js：

```powershell
node server/server.js
```

然后打开 `http://127.0.0.1:4173/`。

## 内容

- 八个阵营：普卫岛、学院、西昭、洛斯汰聚落、共和国、帝国、灰港同盟、雪都
- 633 张卡牌总量：589 个可收藏条目（529 张主卡 + 60 件装备）、18 张衍生卡与 10 张彩蛋卡
- 经典单人 AI、牌组编成、新手教程、图鉴、成就
- 远征、竞技场、每日挑战、残局、旧日故事、镜像对决
- 在线匹配与组队码房间
- 音效、BGM、过场视频、即梦技能图标

## 操作

- 手牌默认**拖拽出牌**；设置里可切换为双击出牌或单击出牌
- 随从拖到阵位，或拖到敌方目标攻击
- 右下角结束回合
- 对局中「设置」直接打开完整设置：音量、画面、AI 速度、震动、动画速度、手牌操作
- 任意界面按 Esc 返回上一层；联机/备战返回二级菜单，不会直接回主菜单

## 测试

### 逐卡效果测试台

启动游戏服务后打开：

    http://127.0.0.1:4173/card-lab.html

测试台会逐张执行 589 张可收藏卡，显示 PASS / WARN / FAIL、效果字段、触发事件和实际状态证据，可筛选并导出 JSON / CSV。

命令行：

```powershell
node tools/card-effect-lab.js --verbose
```

报告会写入 `tests/card-effect-report.json`。

### 沙盒对局作弊台

启动游戏服务后打开：

    http://127.0.0.1:4173/cheat.html

左侧是真实对局界面，右侧是作弊控制台。可以修改双方生命、护甲、行动力、流脉、回合、遗物、手牌、牌库和场上随从；支持添加任意卡牌、召唤任意随从、改攻血/关键词、击杀触发余响、清场、铺场、重开和导出局面 JSON。

“卡牌库/牌组”页支持按卡名、阵营、类型、行动力筛选任意卡牌，选中后一键加手牌、加牌库、召唤；牌库按卡牌分组显示，可增减、补到 30 张、复制牌组。

“AI 调试”页可以启停 AI、选择 AI 阵营和难度、调整步间延迟、单步执行、跑完整回合、强制切换当前玩家；AI 直接调用真实 `GokAI` 决策与引擎动作。另有一键“双 AI 自动推演”，双方连续互打；“观察视角”可锁定玩家 1/2，AI 换手时画面不跳。

## 卡牌断言

新增/改卡后先跑：

```bash
npm run assert:cards
```

会校验卡牌 ID/重名、阵营与稀有度配额、效果类型是否有引擎分支、装备/阵型字段、文案触发词、30 张预组、全部卡牌可打出，以及阵型/装备/技能回归。


## 账号与云存档

- 游客可以直接游玩单人、休闲房间和娱乐模式，但不能进入排位。
- 注册/登录使用用户名 + 密码；会话保存在 HttpOnly Cookie 中。
- 本地存档优先，登录后同步云端；云存档冲突时在「个人资料 → 存档同步」处理。
- 本地开发默认使用 `server/data/gok.db`（SQLite）。
- 线上免费方案使用 Neon / Supabase 的 Postgres：设置 `DATABASE_URL`，不需要挂 Render 持久化磁盘。
- 如果坚持使用 Render 磁盘，则设置 `GOK_DATA_DIR=/var/data` 并挂载磁盘；普通临时文件系统重新部署会丢账号。
- 使用 Postgres 时线上 Node 版本必须为 24。
